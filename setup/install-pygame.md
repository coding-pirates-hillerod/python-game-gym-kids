# Installer Pygame 🎮

Pygame gør det muligt at lave spil med Python.

## Installer Pygame

Åbn Terminal.

Skriv:

```bash
pip install pygame
```

Tryk Enter.

Vent til installationen er færdig.

---

## Test at Pygame virker

Skriv:

```bash
python
```

Derefter:

```python
import pygame
```

Hvis der ikke kommer nogen fejl, virker Pygame.

Skriv:

```python
exit()
```

for at lukke Python igen.

🎉 Klar til at lave spil.
