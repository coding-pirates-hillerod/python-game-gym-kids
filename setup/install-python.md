# Installer Python 🐍

Python er programmeringssproget, som vi bruger til at lave spil.

## 1. Download Python

Gå til:

https://www.python.org/downloads/

Klik på:

**Download Python**

---

## 2. Start installationen

Når installationsprogrammet åbner:

✅ Sæt flueben i:

```text
Add Python to PATH
```

Dette er vigtigt.

Klik derefter:

```text
Install Now
```

---

## 3. Test at Python virker

Åbn Terminal.

Skriv:

```bash
python --version
```

Hvis du ser noget i stil med:

```text
Python 3.13.x
```

så virker Python.

🎉 Klar til næste trin.
