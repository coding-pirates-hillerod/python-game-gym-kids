# Installer VS Code 💻

VS Code er den editor, vi bruger til at skrive kode.

## 1. Download VS Code

Gå til:

https://code.visualstudio.com/

Klik:

```text
Download
```

Installer programmet.

---

## 2. Åbn projektet

Start VS Code.

Vælg:

```text
File → Open Folder
```

Vælg mappen:

```text
python-game-gym-kids
```

---

## 3. Installer Python-udvidelsen

Klik på:

```text
Extensions
```

Søg efter:

```text
Python
```

Installer udvidelsen fra Microsoft.

---

## 4. Vælg Python

Tryk:

```text
Ctrl + Shift + P
```

Søg efter:

```text
Python: Select Interpreter
```

Vælg den nyeste installerede Python-version.

---

## 5. Start dit første spil

Åbn:

```text
games/01_move_square/game.py
```

Klik på:

▶ Run

eller kør:

```bash
python game.py
```

🎉 Nu er du klar til at lave spil.
