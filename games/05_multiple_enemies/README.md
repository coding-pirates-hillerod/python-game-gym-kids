# 05 - Flere fjender 👾👾👾

Nu er der ikke bare én fjende.

Der er mange!

Undgå de røde fjender så længe som muligt.

For hver fjende, der flyver forbi dig, får du point.

Hvis du bliver ramt, mister du liv.
