# Python Game Gym for Kids 🎮🐍

Lær Python ved at lave spil.

Ingen kedelige terminalprogrammer.

Ingen endeløs teori.

Bare spil.

---

## Hvad er det her?

Python Game Gym for Kids er en samling af små spil lavet med Python og Pygame.

Hvert spil introducerer nogle få nye programmeringsbegreber, samtidig med at det er sjovt at spille og ændre.

Målet er ikke at lære en masse teori udenad.

Målet er at:

- Køre spil
- Spille spil
- Ændre spil
- Forstå spil
- Bygge sine egne spil

---

## Sådan fungerer det

Hvert spil følger den samme proces:

### 1. Spil

Start spillet og prøv det.

### 2. Hack

Lav små ændringer.

For eksempel:

- Gør spilleren hurtigere
- Skift farver
- Tilføj flere fjender
- Få flere point

### 3. Byg

Tilføj dine egne idéer.

## Missioner

I stedet for traditionelle øvelser arbejder vi med missioner.

Eksempel:

✅ Gør spilleren hurtigere

✅ Skift spillerens farve

✅ Tilføj en ekstra fjende

✅ Fordobl antallet af point

✅ Lav en ny power-up

Den bedste måde at lære programmering på er ved at eksperimentere.

---

## For forældre, lærere og frivillige

Børn mister hurtigt motivationen, hvis de bruger mere tid på fejl og værktøjer end på at lave spil.

Derfor fokuserer dette repository på:

- Små projekter
- Synlige resultater
- Færdig kode der virker
- Progressiv sværhedsgrad
- Læring gennem leg og nysgerrighed

Spillene er designet, så børn kan starte med at ændre nogle få værdier og gradvist forstå mere og mere af koden.

---

## Det endelige mål

Målet er ikke at gennemføre alle spillene.

Målet er, at et barn kan sige:

> "Det har jeg selv lavet!"

... og derefter bliver nysgerrig efter at forstå, hvordan det virker.

God fornøjelse med kodningen! 🎮🐍
